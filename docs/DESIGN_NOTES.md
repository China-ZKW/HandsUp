# UI 设计方向

参考图：`D:\Downloads\screenshot_20261009_112101.jpg`

后期功能稳定后，整体界面向参考图靠拢。当前阶段优先验证窗口截图、裁剪和提问链路，不进行大规模换肤。

## 视觉关键词

- 黑白与暖灰为主，减少高饱和蓝色的面积
- 大面积留白，信息层级简洁
- 大圆角窗口与卡片，边框弱化
- 轻微阴影、半透明和背景模糊
- 黑色主按钮，白色或浅灰次级按钮
- 操作区尽量悬浮化，减少传统桌面软件感
- 图标使用细线、统一尺寸，避免彩色 emoji
- 字体粗细形成层级，不依赖过多颜色

## 适配到 PC 课堂助手

- 顶部保留课程名称、当前窗口状态和设置入口
- PPT 预览作为最大的主卡片
- 快捷问题改成黑白胶囊按钮
- 提问输入框与发送按钮组成底部悬浮操作条
- AI 回答以抽屉或浮层卡片展示，避免占满窗口
- 课程记录与收藏功能成熟后，再增加类似底部导航的模块切换

## 暂不照搬的部分

- 不模拟手机状态栏和手机外框
- 不为装饰引入无关照片
- 不牺牲截图预览面积和课堂操作速度
