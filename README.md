# HandsUp：PC 课堂 PPT 学习助手

一个 Windows 桌面原型：选择显示同步 PPT 的微信窗口，框选课件区域，然后针对当前页面快速向 AI 提问。

0.2.0 起采用横向课堂工作台：左侧显示 PPT，右侧完成提问和阅读答案，并使用黑白极简、大圆角卡片的界面风格。

0.2.1 为主要卡片加入半透明磨砂玻璃、背景模糊和柔和环境光效果。

## 当前功能

- 选择窗口或屏幕并截取当前画面
- 在预览图中拖拽框选 PPT 区域
- 四个课堂快捷问题和自由提问
- 默认先给简短结论，避免课堂上阅读长篇回答
- 用“画面清晰 / 部分不清 / 需要重选区域”标记识图状态
- 可展开查看模型引用的截图依据；关键内容看不清时不猜测
- 支持在设置中切换 OpenAI 与 DeepSeek Flash，两套 API 密钥分别加密保存
- `Alt + Q` 全局快捷键呼出窗口
- AI 回答窗口始终置顶
- API 密钥通过 Electron `safeStorage` 使用 Windows 系统能力加密保存
- 请求设置为 `store: false`

后续 UI 换肤方向见 [`docs/DESIGN_NOTES.md`](docs/DESIGN_NOTES.md)。

## 安装与运行

需要 Node.js 20 或更高版本。

```powershell
pnpm install
pnpm start
```

如果使用已经构建的 Windows ZIP：

1. 解压整个压缩包，不要只单独复制 `.exe`。
2. 双击解压目录中的 `HandsUp.exe`。
3. Windows 若提示来源未知，可先查看文件属性；当前原型尚未购买代码签名证书。

首次使用：

1. 点击右上角设置按钮。
2. 选择 OpenAI 或 DeepSeek Flash，填写对应的 API 密钥并保存。
3. 点击“选择窗口”，选择正在显示课程 PPT 的微信窗口。
4. 如有需要，在画面上拖拽框选 PPT 区域。
5. 选择快捷问题或输入自己的问题，点击“截取当前页并提问”。

回答区默认只显示短答案。需要确认模型读到了什么时，可以展开“查看识别依据”；出现“需要重选区域”时，重新框选文字或公式后再提问。

## 隐私说明

- 程序不会读取微信账号、Cookie 或网络请求。
- 只有在点击提问时，当前截图（或框选区域）和问题才会发送给模型。
- API 密钥不会传给渲染页面，而是在 Electron 主进程中使用。
- 请遵守课程、学校和课件版权所有者的规定，不要处理不应外传的材料。

## 原型限制

- 被选择的窗口不能最小化；某些受保护窗口可能无法截图。
- 当前版本不会持续监听老师讲话，也不会持续上传屏幕。
- 开发模式通过 `pnpm start` 运行；程序目录通过 `pnpm run pack-dir` 构建。
- 当前原型未签名，Windows 可能显示未知发布者提示。
